## First push

Run these commands inside the unzipped project folder after creating an empty GitHub repository with the name above:

```bash
git init
git add .
git commit -m "Build explainable deal intelligence platform"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/sauda-deal-intelligence.git
git push -u origin main
```

Do not ask GitHub to generate a README, `.gitignore`, or license when creating the empty repository; they are already included here.
